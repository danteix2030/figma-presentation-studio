# Política de privacidade do figs.dec

Última atualização: 8 de setembro de 2026.

O figs.dec processa no próprio plugin as informações das pranchetas selecionadas, incluindo nomes de layers, textos, estilos visuais, imagens e configurações de apresentação. Esses dados são usados apenas para montar a prévia e os arquivos solicitados pelo usuário.

As configurações do projeto são gravadas como plugin data dentro do próprio arquivo do Figma. O figs.dec não envia o conteúdo do arquivo para servidores próprios.

Quando o usuário escolhe exportar para Google Apresentações, o plugin envia a apresentação gerada diretamente à API do Google Drive usando o token OAuth fornecido pelo próprio usuário. O token não é enviado a servidores do figs.dec e, quando o ambiente permite, permanece somente durante a sessão do plugin. O arquivo criado fica sujeito às configurações e à política de privacidade da conta Google do usuário.

O plugin não vende dados pessoais, não usa o conteúdo dos arquivos para publicidade e não realiza rastreamento de comportamento.

Solicitações de suporte ou privacidade podem ser abertas em https://github.com/danteix2030/figma-presentation-studio/issues.
